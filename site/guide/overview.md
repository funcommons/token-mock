# 概述

**token-mock** 是一个独立的多厂商 LLM API Mock 服务:单端口模拟 OpenAI / Anthropic / Gemini / Azure OpenAI / AWS Bedrock / Ollama 六种协议,同一个 Spring Boot fat jar 内置 12 家厂商、文本/语音/图片/视频全模态响应,并支持运行时故障注入与限流仿真。

## 它解决什么问题

给 LLM 应用做集成测试,通常只有两条路:

1. **调真实 API** — 烧钱、慢、结果不确定、没法复现失败;
2. **在业务代码里写假实现** — 侵入代码、覆盖不到协议细节(SSE 分块、tool_calls、429 语义…)。

token-mock 提供第三条路:**把"假 LLM"做成独立服务**,按真实厂商的协议返回响应,业务侧只需把 `base_url` 指过来,一行代码不改。

典型用途:

- **集成测试** — CI 里 `docker run` 拉起,跑完销毁;测试断言协议结构而非模型输出
- **故障演练** — 注入 500 / 延迟 / 429,验证重试、降级、熔断、限流逻辑
- **Demo 演示** — 断网环境也能完整演示多厂商对话 / 语音 / 图片 / 视频功能
- **压测** — 用管理接口把延迟、失败率调成目标场景,测客户端吞吐

## 目标与非目标

### 目标

- **独立可启**:一个 Spring Boot fat jar,无外部依赖(PG / Redis / Kafka 都不需要)
- **多厂商协议**:6 种协议、同协议多厂商(OpenAI 协议族下 7 家)、每家独立 key 与模型清单
- **多模态**:文本 / 声音(TTS+STT)/ 图片(生成+理解)/ 视频(异步生成)
- **行为完整**:非流式 / SSE 流式 / 工具调用 / Embeddings / 多模态回显
- **故障注入**:按比例返回 4xx/5xx / 模拟延迟 / 强制连续失败
- **OpenAPI 文档**:Swagger UI 可视化 + 在线调试

### 非目标

- ❌ 不做真实推理(返回固定/回显内容,不调用任何真实模型)
- ❌ 不做持久化(重启即清空,所有状态在内存)
- ❌ 不做用户管理(单 admin token 保护管理接口)
- ❌ 不做高可用(单实例,开发/测试用途)
- ❌ 不做真实音视频编解码(返回固定二进制占位文件,校验协议而非内容)

## 整体架构

```
┌────────────────────────────────────────────────────────────────┐
│                    token-mock (port 9999)                      │
│                                                                │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐          │
│  │  OpenAI      │  │ Anthropic    │  │  Gemini      │  ...     │
│  │  Protocol    │  │ Protocol     │  │  Protocol    │  (6 个)  │
│  │  Handler     │  │ Handler      │  │  Handler     │          │
│  └──────┬───────┘  └──────┬───────┘  └──────┬───────┘          │
│         └────────┬────────┴────────┬────────┘                   │
│                  ▼                 ▼                            │
│         ┌──────────────────────────────────┐                    │
│         │     Vendor Registry (内存)       │                    │
│         │  - slug → protocol / key / models│                    │
│         │  - 配置在 application.yml        │                    │
│         └────────────────┬─────────────────┘                    │
│         ┌────────────────▼─────────────────┐                    │
│         │   Response Generator             │                    │
│         │  - 模板响应 (echo / fixed)       │                    │
│         │  - Token 估算 (字数/4)           │                    │
│         │  - SSE 分块                      │                    │
│         └────────────────┬─────────────────┘                    │
│         ┌────────────────▼─────────────────┐                    │
│         │   Fault Injector                 │                    │
│         │  - 失败率 / 延迟 / 状态码         │                    │
│         └────────────────┬─────────────────┘                    │
│         ┌────────────────▼─────────────────┐                    │
│         │   RateLimiter (令牌桶)           │                    │
│         │  - QPS / Tokens-per-second       │                    │
│         │  - 突发容量 (burst)              │                    │
│         │  - 429 + Retry-After             │                    │
│         └────────────────┬─────────────────┘                    │
│         ┌────────────────▼─────────────────┐                    │
│         │   Modality Router                │                    │
│         │  - chat / embed / tts / stt      │                    │
│         │  - image-gen / image-vision      │                    │
│         │  - video-gen (异步)              │                    │
│         └────────────────┬─────────────────┘                    │
│         ┌────────────────▼─────────────────┐                    │
│         │   Placeholders (内置二进制资源)   │                    │
│         │  - silence-1s.mp3 (TTS)          │                    │
│         │  - placeholder-256x256.png       │                    │
│         │  - placeholder-5s.mp4            │                    │
│         └──────────────────────────────────┘                    │
│                                                                │
│  ┌────────────────────────────────────────────────────────┐    │
│  │  管理接口 (/admin/**, X-Mock-Admin-Token 保护)          │    │
│  │  - GET/POST /admin/vendors/{slug}/faults   故障注入     │    │
│  │  - GET/POST /admin/vendors/{slug}/rate-limit 限流       │    │
│  │  - GET /admin/stats   请求计数 / 延迟分位               │    │
│  └────────────────────────────────────────────────────────┘    │
│                                                                │
│  ┌────────────────────────────────────────────────────────┐    │
│  │  springdoc-openapi (Swagger UI @ /swagger-ui.html)     │    │
│  └────────────────────────────────────────────────────────┘    │
└────────────────────────────────────────────────────────────────┘
         ▲
         │ HTTP
         │
   ┌─────┴──────────────────────────────┐
   │ 调用方:                             │
   │  - 任何 OpenAI 兼容客户端           │
   │  - Spring AI / LangChain 等框架     │
   │  - 网关/中转平台 (channel 直指 mock) │
   └────────────────────────────────────┘
```

请求处理链:**路径前缀 → 厂商识别 → key 校验 → 限流 → 故障注入 → 模态路由 → 响应生成**。

## 技术栈

| 项 | 值 |
|---|---|
| 语言 / 编译目标 | Java 21(虚拟线程已启用) |
| 框架 | Spring Boot 3.5(spring-boot-starter-web / validation / actuator) |
| API 文档 | springdoc-openapi 2.3(Swagger UI + 分组) |
| 构建 | Maven,产物 `token-mock.jar`(Spring Boot fat jar) |
| 默认端口 | 9999 |
| 状态 | 全内存,重启即清空 |
